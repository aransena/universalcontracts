# Synthetic Dataset Contract v1

Contract ID: `universal.sim.synthetic_dataset.v1`

## Purpose

Describe a dataset generated by simulation, rendering, augmentation, or synthetic
data production.

## Required Shape

A synthetic dataset descriptor should include:

- `schema`: `universal.sim.synthetic_dataset.v1`.
- `id`: stable dataset ID.
- `kind`: `synthetic_dataset`.
- `created_at`: ISO 8601 UTC timestamp.
- `producer`: generator project and version.
- `sources`: scenarios, simulation runs, assets, prompts, or real seed data.
- `files`: data, labels, metadata, schemas, previews, and checksums.
- `generation`: parameters, seeds, engine, and augmentation rules.
- `fields`: output fields, labels, units, and formats.
- `quality`: validation, coverage, diversity, and known limitations.

## Extension Points

Projects may add domain-specific label schemas, rendering settings, privacy
analysis, sensor models, or train/validation/test splits.

## Invariants

- Synthetic origin is explicit.
- Generation parameters and sources are traceable.
- Labels and units are declared.
- Limitations are recorded for downstream model training or evaluation.

## Validation Rules

- Resolve source and data file references.
- Warn when generated data lacks seed or parameter metadata.
- Warn when labels lack schema references.

## Agent Implementation Notes

Use this contract to hand synthetic data to visualization, training, evaluation,
and sharing systems.
