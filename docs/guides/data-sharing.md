# Guide: Sharing or Publishing Data

## Start Here

Use:

- `universal.data.dataset.v1`
- `universal.core.manifest.v1`
- `universal.core.provenance.v1`
- `universal.core.permissions.v1`

If data was generated by a job, add:

- `universal.data.pipeline_run.v1`
- `universal.core.lifecycle.v1`
- `universal.core.test_run.v1`

## Add Source-Specific Contracts

For sensor or telemetry recordings:

- `universal.capture.recording_bundle.v1`
- `universal.core.stream.v1`
- `universal.capture.payload_index.v1`

For documents:

- `universal.knowledge.document_corpus.v1`
- `universal.knowledge.document.v1`
- `universal.knowledge.extraction_run.v1`

For media:

- `universal.media.media_asset.v1`
- `universal.media.rendition.v1`

## Agent Checklist

1. Identify files, schemas, fields, units, and record counts.
2. Declare sources and checksums.
3. Mark privacy, rights, retention, and license status.
4. Keep custom columns additive and documented.
5. Add an example descriptor that a generic consumer can inspect.
